# LeadMind AI

LeadMind AI — это веб-приложение на Python, которое работает как AI CRM-агент для обработки входящих заявок бизнеса.

Проект принимает сообщение клиента, анализирует заявку, определяет важные параметры, сохраняет результат в PostgreSQL и показывает аналитику на дашборде.

## 1. Бизнес-проблема

Малый бизнес часто теряет клиентов из-за медленной и неструктурированной обработки заявок.

Основные проблемы:

- менеджеры долго отвечают клиентам;
- горячие заявки теряются среди обычных сообщений;
- данные плохо фиксируются в CRM;
- руководитель не видит общую картину по заявкам;
- менеджер тратит время на ручной первичный анализ.

LeadMind AI помогает автоматизировать первичную обработку заявок и быстрее передавать менеджеру понятный результат.

## 2. Решение

Система анализирует входящее сообщение клиента и определяет:

- тип услуги;
- площадь объекта;
- город или район;
- сроки начала работ;
- бюджет;
- горячесть заявки;
- недостающие данные;
- следующий шаг для менеджера;
- готовый ответ клиенту.

Пример заявки:

```
Здравствуйте, нужен ремонт дома 150 м² в Краснодаре. Хотим начать через месяц, бюджет 2500000 рублей.
```

Пример результата:

```
Тип услуги: Ремонт дома
Площадь: 150 м²
Локация: Краснодар
Сроки: В течение месяца
Бюджет: 2500000 рублей
Оценка заявки: Горячая
```

## 10. Описание файлов

### `app/main.py`

Главный файл приложения. В нем описаны маршруты сайта:

```
GET  /
POST /analyze
GET  /leads
POST /leads/{lead_id}/status
GET  /dashboard
```

### `app/ai_agent.py`

Файл с логикой агента. Он анализирует сообщение клиента и возвращает структурированный результат.

Сейчас работает demo-режим на Python-правилах. Также есть заготовка для OpenAI API.

### `app/prompts.py`

Файл с системной инструкцией для будущего AI-агента OpenAI и JSON-схемой ответа.

### `app/config.py`

Файл настроек. Читает данные из `.env`.

### `app/database.py`

Файл подключения к PostgreSQL через SQLAlchemy.

### `app/models.py`

Файл модели базы данных. Содержит таблицу `Lead`.

### `templates/index.html`

Главная страница с формой новой заявки.

### `templates/leads.html`

Страница списка всех заявок и смены статусов.

### `templates/dashboard.html`

Страница аналитики.

### `static/style.css`

Файл стилей интерфейса.

## 11. Модель базы данных

Таблица:

```
leads
```

Поля таблицы:

| Поле | Описание |
|---|---|
| id | ID заявки |
| original_message | исходное сообщение клиента |
| summary | краткое резюме |
| service_type | тип услуги |
| area | площадь |
| location | город или район |
| timeline | сроки |
| budget | бюджет |
| lead_score | горячесть заявки |
| status | CRM-статус |
| missing_data | недостающие данные |
| next_step | следующий шаг |
| client_reply | ответ клиенту |
| created_at | дата создания |

## 12. Настройки `.env`

Пример файла `.env`:

```env
AI_MODE=demo
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4o-mini

DB_HOST=localhost
DB_PORT=5432
DB_NAME=leadmind_ai
DB_USER=postgres
DB_PASSWORD=your_password
```

`AI_MODE=demo` означает, что проект работает без внешнего AI API.

Для подключения OpenAI API в будущем:

```env
AI_MODE=openai
OPENAI_API_KEY=your_openai_api_key
```

## 13. Установка зависимостей

Создать виртуальное окружение:

```powershell
python -m venv .venv
```

Активировать окружение:

```powershell
.venv\Scripts\activate
```

Установить зависимости:

```powershell
pip install -r requirements.txt
```

## 14. Настройка PostgreSQL

В pgAdmin нужно создать базу данных:

```
leadmind_ai
```

После этого указать данные подключения в `.env`.

## 17. Сценарий демонстрации

1. Запустить сервер.
2. Открыть главную страницу.
3. Ввести тестовую заявку.
4. Нажать “Проанализировать заявку”.
5. Показать результат анализа.
6. Перейти на страницу “Все заявки”.
7. Показать сохраненную заявку.
8. Изменить статус на “В работе”.
9. Перейти на дашборд.
10. Показать обновленную аналитику.

## 18. Почему это AI-агент

AI-агент не просто отвечает на вопрос, а выполняет бизнес-задачу.

В этом проекте агент:

- принимает сообщение клиента;
- извлекает данные;
- оценивает заявку;
- готовит следующий шаг;
- формирует ответ клиенту;
- сохраняет результат в CRM.
