# LeadMind AI — Асинхронный AI CRM-агент для автоматизации обработки входящих лидов

**LeadMind AI** — это высокопроизводительный бэкенд-сервис на базе FastAPI, функционирующий как интеллектуальный CRM-агент для автоматической обработки, скоринга и структурирования входящих текстовых заявок бизнеса с помощью LLM-моделей.

Проект решает проблему медленной первичной обработки неструктурированных лидов, автоматически категоризирует их по степени готовности к покупке («температуре»), сохраняет в реляционную БД и агрегирует метрики для аналитического дашборда.

---

## 🛠 Технологический стек и архитектура

*   **Backend фреймворк:** FastAPI (асинхронная обработка запросов, высокая пропускная способность).
*   **ИИ-компонент:** OpenAI API / Интеграция LLM (структурированный output-парсер, JSON-schema валидация ответов).
*   **База данных и ORM:** PostgreSQL, SQLAlchemy (Async Engine), Alembic (миграции).
*   **Валидация данных:** Pydantic v2 (строгая типизация входящих и исходящих DTO-моделей).
*   **Архитектурные паттерны:** Слой репозиториев (Repository Pattern) для изоляции работы с БД, Сервисный слой (Service Layer) для бизнес-логики и интеграции с LLM.
*   **Сервер и окружение:** Uvicorn, Python-dotenv, Git/GitHub.

---

## 🚀 Ключевой функционал и инженерные решения

1. **Structured Data Extraction (Извлечение сущностей):** Реализован конвейер обработки текста, который с помощью системных промптов и JSON-валидации Pydantic извлекает из сырого текста именованные сущности (Тип услуги, Бюджет, Сроки, Локация, Метраж).
2. **Автоматический Lead Scoring:** ИИ-агент на основе комплексного анализа текста классифицирует лид по шкале `Hot / Warm / Cold` и генерирует оптимальный "Next Step" (следующий шаг) для менеджера, минимизируя человеческий фактор.
3. **Аналитический Дашборд:** Разработаны API-эндпоинты для агрегации метрик эффективности (общее количество лидов, конверсия по статусам, распределение по «температуре» лидов) с последующим выводом в дашборд.
4. **CRM-логика:** Реализован классический конечный автомат состояний для заявок (`Новая` -> `В работе` -> `Закрыта`) с валидацией переходов.

## 📈 Пример работы конвейера

### 📥 Входной сырой текст (Сообщение клиента):
> *"Здравствуйте, нужен ремонт дома 150 м² в Краснодаре. Хотим начать через месяц, бюджет 2500000 рублей."*

### 📤 Выходной валидированный JSON (Ответ API):
```json
{
  "status": "success",
  "lead_data": {
    "service_type": "Ремонт дома",
    "area_sq_m": 150.0,
    "location": "Краснодар",
    "timeline": "В течение месяца",
    "budget": 2500000,
    "scoring_class": "Hot",
    "next_action": "Срочно связаться, предложить типовой проект для 150 кв.м в Краснодаре",
    "missing_fields": []
  }
}
```

## 🔧 Инструкция по локальному развертыванию

### 1. Клонирование репозитория и настройка окружения
```bash
git clone https://github.com
cd LeadMind-AI
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Конфигурация переменных окружения
Создайте файл `.env` в корневой директории проекта:
```env
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/leadmind_db
OPENAI_API_KEY=your_openai_api_key_here
SECRET_KEY=your_jwt_secret_key
```

### 3. Запуск приложения
```bash
uvicorn main:app --reload
```
После запуска интерактивная документация API (Swagger) будет доступна по адресу: `http://127.0.0`
